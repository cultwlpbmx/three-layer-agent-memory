# 模板套件

复制本目录、重命名为项目名，即可得到一个符合三层记忆范式的项目库。

## 复制后应包含

```
<项目名>/
├── 表层/
│   ├── 00-项目总览.md
│   └── 01-待完成任务.md
├── 中层/
│   ├── INDEX-任务流水.md
│   └── _任务模板.md        # 留作后续复制用，不删除
└── 深层/
    └── AI深度思考.md
```

## 填写顺序

1. `表层/00-项目总览.md` —— 至少填到"核心目的"；宗旨/哲学有就逐字保留、没有留占位
2. 在库根 `INDEX.md` 加一行指针
3. `表层/01-待完成任务.md` —— 列当前待办
4. 开记第一篇 `中层/` 任务记录（从 `_任务模板.md` 复制）
5. `深层/AI深度思考.md` —— 第一次可写一段对项目现状的整体审视

## 协议

填写后，让你的 agent 按 `../PROTOCOL.md` 的三个检查点运行即可。无需任何运行时依赖。
